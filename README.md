Автор big_energy. Версия сборки 2.0.3, Minecraft 1.20.1, Forge 47.4.10 и Java 17. Официальный клиент CurseForge `1771794/9558909` весит 2 214 600 байт. SHA‑256 `23e5968067ad91b55e60bbd85ecd0de3b5a8a46cf7d06f6684c8d565f0d62580`. В исходный lock входят 161 обязательная зависимость и 1011 файлов авторского слоя. [Выпуск 2.0.3](https://www.curseforge.com/minecraft/modpacks/antimatter-chemistry-reforged/files/9558909)

Сборка занимает ID `minecraft-17` и использует собственную папку `Antimatter Chemistry Reforged`. В каталоге следует изменить только строку `minecraft-17`, без алиасов старой папки или источника. Миры Antimatter Chemistry 1.4.10 остаются по своему пути.

## Подготовка и приёмка

Укажите путь к официальному ZIP через `$authorZip`. `$stage` должен быть новой папкой внутри своего `artifacts/agent-runs/<task-id>` с `RUN.json`. Из корня исходников LANMinecraft выполните стандартную подготовку CurseForge из [инструкции](https://github.com/MarkZamore/LANMinecraft/blob/main/tools/PackData/CurseForge/README.md). `tools/upstream-client-lock.json` закрепляет входные файлы. `tools/overlay.json` связывает их со слоем журнала и параметром сохранения настроек мира при открытии сети.

На точном Forge 47.4.10 проверьте создание мира через `minecraft:normal`, появление на равнине антиматерии и выдачу стартового набора в инвентарь через `amworld:first_join`. После повторного входа проверьте квесты и отсутствие повторной выдачи набора. Отдельно проверьте скины, локальное подключение хоста и гостя, сообщения после открытия мира, пропуск промежуточного окна, кнопку «Жалобы», сохранение режима и выполнение `/time` гостем при разрешённых командах. Для тестов нужен отдельный экземпляр со своим миром.
