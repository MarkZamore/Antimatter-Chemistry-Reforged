# Управление в Antimatter Chemistry Reforged

Источник списка — строки `key_` из сохранённого `options.txt` запущенного ранее Reforged 2.0.3 (Minecraft 1.20.1, Forge 47.4.10). Для этого пресета клиент не запускался. Список фиксирует назначения, записанные клиентом, и может не охватывать моды, которые читают кнопки напрямую или регистрируют действия после входа в мир.

Генератор сохраняет базовые назначения Minecraft. Карта FTB Chunks остаётся на M, книга заданий открывается на B, рюкзак на G, Curios на H, рецепты и применения JEI на R и U. Меню инструмента и пояс Create используют левый и правый Alt соответственно. Прыжок остаётся на пробеле. Конфликтующие с ним подъём реактивного ранца Electrodynamics и запуск ботинок PneumaticCraft вынесены на цифровой блок.

Сверены реализация `KeyMapping.same` целевого Forge и отдельные контексты JEI в установленном JAR. Для всех назначений применили более строгую проверку: у двух привязанных действий нет общей физической клавиши даже в разных контекстах. Сочетания Shift, Ctrl и Alt учитывались при переносе: базовые клавиши-модификаторы сохраняются, а конфликтующие сочетания получают отдельную клавишу или снимаются. Среди снятых назначений есть альтернативные кнопки мыши JEI и горячие клавиши чит-режима. Клавиши F1–F4 и системные клавиши не отдаются модам. Проверка за пределами игры не моделирует внутренние обработчики и условные действия конкретных предметов.

Воспроизведение из корня репозитория:

```powershell
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py
```

Для выпуска одной раскладки запустите `publish.yml` с параметром `controls_base`, равным SHA-256 актуального манифеста `pack-latest`. Задание сверяет состав предыдущего выпуска и обновляет манифест после проверки новых файлов на GitHub. Полная сборка также прикрепляет проверенный пресет. При смене состава модов сначала обновите список `registered-keys.txt` и проверьте назначения.
